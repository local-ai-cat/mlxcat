## Decisions for the native Swift port

| Practice | Source | Adopt in mlxcat |
| --- | --- | --- |
| Restart each core pass from the prelude and route top-8 experts again after blending previous-pass messages | mlx-vlm `language.py`; independently Ollama `model.go` and vLLM `nvidia/loop.py` | **Yes.** This defines Mini's forward pass. Preserve dtype boundaries and build one visit schedule from config. |
| Separate KV and recurrent state for all 48 visits | mlx-vlm `language.py:880`, Ollama `model.go:138`, vLLM `nvidia/model.py:164` | **Yes.** Serialize both state types, retain global and sliding semantics, and test cached continuation across a sliding-window wrap. Sharing weights does not make the resulting KV interchangeable. |
| Packed expert banks and separate outer scales | mlx-vlm `inkling2.py`, baytizzel `verify-against-release.py`, mlx-swift `Ops.swift` | **Yes.** Preserve the checkpoint representation and verify each format's scale order with isolated expert tests. |
| Byte-for-byte template tests and typed streaming parser | Ollama `model/renderers/inkling2_reference_test.go` and `model/parsers/inkling2_test.go`, vLLM Rust renderer/parser fixtures | **Yes.** Check reasoning, tools, escaped content, split markers, tool round trips and truncation. Compare input IDs against mlx-vlm. |
| Processor-owned image placeholders and embedding substitution | mlx-vlm `processing_inkling2.py` and `inkling2.py:21` | **Yes.** Compare placeholder positions and image-prefill logits before enabling image batching. |
| Left-padding, chunked prefill and independent per-row extraction | mlx-lm `generate.py` and `models/cache.py`, baytizzel `results/RESULTS.md` | **Yes.** Exercise mixed-length batches against serial generation, including cached rows, window wrap and state extraction. Include every visit's conv state in admission accounting. |
| Credit retained prefix memory and avoid redundant full-cache copies | baytizzel fork `b23fbbca`, `172c5777`, `1f269dc0`, `7ecb8083`; oMLX serving cache | **Yes, after parity.** Preserve ownership and cancellation semantics. Measure continuation TTFT and peak memory before and after. |
| Grouped expert matvec, fused short convolution, relative-attention kernels and split-K | mlx-vlm follow-ups #2796–#2798, Ollama `experts.go`, baytizzel `388417c0`, `35a574c1` | **Yes, selectively.** Compare only after establishing the reference forward. Measure prefill and decode independently and use teacher-forced logits to distinguish rounding from state bugs. |
| GPTQ/oQ requantization, KV8 and DSpark on the initial parity path | VisualInference `extras/scripts`, mlx-community cards, baytizzel `6282caa0`, vLLM recipe | **No.** Evaluate as opt-in variants after packed-weight and unquantized-KV parity. Each changes the quality, memory or verification tradeoff. |
| CUDA kernels and GPU-resident paged caches | vLLM `nvidia/ops` and recipe | **No.** Reuse the visit identity and cache-accounting ideas with Swift MLX and mlxcat's existing prefix tiers. |
